# 이번 주

이번 주 할 일을 요일별로 적고, 고치고, 완료하고, 지우는 개인용 웹 앱입니다.

## 실행 방법

`index.html`을 브라우저에서 엽니다.

## 되는 것

- 할 일 추가
- 요일 선택 (월~일, 언제든)
- 추가할 때 기본 요일은 오늘
- 오늘 요일 표시
- 이번 주 목록을 요일별로 보기
- 이번 주 진행 상황 (완료 개수)
- 할 일이 없는 요일은 감추기 (오늘은 항상 보임)
- 완료 처리
- 할 일 수정
- 할 일 삭제
- 지난주에 남은 미완료를 이번 주로 넘기기
- 이 브라우저에만 저장
- 파일로 내보내기, 파일에서 가져오기
- 한 주는 월요일~일요일

## 아직 안 하는 것

로그인, 알림, 다른 기기 동기화는 아직 없습니다.

## 파일 위치

- `index.html` — 화면
- `src/app.js` — 동작
- `src/style.css` — 모양
